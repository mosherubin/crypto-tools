Moshe Rubin's crypto-tools

Browser-based tools for classical cryptanalysis, each with a guide to the method behind it. Find Repetitions locates the repeated sequences within and between ciphertexts that reveal a cipher's period or messages sent in the same key. Literal Key Reconstruction recovers the word or phrase behind a transposition numerical key. Both follow the methods of the classic texts, such as Friedman's Military Cryptanalysis and Callimahos's Military Cryptanalytics. More tools will follow as their guides are written.

Every tool runs in your browser, with nothing to install.

Diagnostics

  • Find Repetitions
    Find repeated sequences within one ciphertext or across several, with the positions where each one occurs.

Transposition ciphers

  • Literal Key Reconstruction
    Recover the word or phrase behind a transposition numerical key, using the keyword reconstruction table.
