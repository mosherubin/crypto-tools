Columnar Transposition Table

Writes a ciphertext into a columnar transposition table under a given write-in key, for both left-to-right (English, etc.) and right-to-left (Hebrew, Arabic, etc.) languages. Prints the completed table, then the row-by-row read-out as ≤50-character lines for visual confirmation.

Lines starting with '#' are treated as comments and ignored. Everything else is concatenated with whitespace stripped.
