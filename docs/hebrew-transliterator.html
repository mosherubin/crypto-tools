Hebrew to Latin Transliterator

STETHOSCOPE and Isomorph Search only recognize printable ASCII, so a Hebrew ciphertext stored in a .cryptml file (e.g. charset: "[א-ת]") can't be run through them directly. This maps each Hebrew letter to a fixed Latin stand-in so the same ciphertext can be analyzed there. This is not a linguistic transliteration -- the mapping is an arbitrary one-to-one substitution, chosen only to give each letter a distinct A-Z stand-in.
